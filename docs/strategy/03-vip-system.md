# HabitHero VIP 系統圖

> 狀態：`[待討論]`。這份文件先整理關係，不代表價格、上限或 VIP 內容已經決定。

## VIP 的產品關係

```mermaid
flowchart TB
    USER[家庭使用者] --> PLAN[選擇方案]
    PLAN --> BILLING[訂閱付款狀態]
    BILLING --> STATUS{訂閱狀態}

    STATUS -->|有效| ENTITLEMENT[VIP 權限集合]
    STATUS -->|未訂閱| FREE[免費版權限]
    STATUS -->|到期或取消| FALLBACK[回到免費版]

    ENTITLEMENT --> CONTENT[VIP 內容]
    ENTITLEMENT --> REPORT[進階成長報告]
    ENTITLEMENT --> WORLD[額外世界、家具、寵物]
    ENTITLEMENT --> STORY[VIP 劇情與冒險]

    FREE --> CORE[基本習慣與冒險核心]
    FALLBACK --> CORE
    CONTENT --> CORE
    REPORT --> PARENT_VALUE[家長得到更完整的回饋]
    WORLD --> CHILD_VALUE[孩子得到更多遊戲回饋]
    STORY --> CHILD_VALUE
```

## 訂閱不應改變的核心原則

- `[待討論]` 免費版仍然能完成基本習慣任務。
- `[待討論]` 免費版仍然能使用基本點數與獎勵流程。
- `[待討論]` VIP 到期後，孩子已完成的紀錄不消失。
- `[待討論]` VIP 到期後，已取得的物品如何處理要明確定義。
- `[待討論]` 家長看到完整付款與權限資訊，孩子看到適合年齡的內容。
- `[待討論]` 不用付費才能避免負面懲罰或維持基本進度。

## VIP 決策順序

```mermaid
flowchart LR
    A[先定義產品價值] --> B[決定免費版核心]
    B --> C[決定 VIP 額外價值]
    C --> D[決定方案與價格]
```

## 需要特別討論的問題

- VIP 是為了增加孩子內容，還是減少家長建立任務的時間？
- VIP 是否包含更多家庭成員或多個孩子？
- VIP 內容是一次購買、月訂閱，還是季節通行證？
- 家長取消訂閱後，已解鎖劇情和已購買物品如何處理？
- 哪些功能不應該收費，否則會傷害習慣養成的核心價值？
- 是否需要試用期、退款後狀態和跨平台恢復購買？
