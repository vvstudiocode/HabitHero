# HabitHero

## 為什麼做

- [待討論] 幫助孩子建立可持續的生活習慣
- [待討論] 讓家長可以用正向方式陪伴孩子成長
- [待討論] 把完成真實生活任務轉換成有感的遊戲回饋

## 使用者

- [決定] 家長
  - 建立與安排冒險任務
  - 審核孩子的完成結果
  - 設定獎勵與家庭規則
  - 觀察長期成長
- [決定] 孩子
  - 查看今日冒險
  - 完成真實生活任務
  - 取得點數與世界回饋
  - 發展角色、寵物與自己的世界
- [想法] 好友
  - 拜訪好友世界
  - 參加合作冒險
  - 使用安全的遊戲式聊天

## 核心循環

- [待討論] 家長設定目標
- [決定] 孩子看到任務
- [決定] 孩子完成真實行動
- [決定] 家長審核

- [待討論] 世界、角色或劇情產生變化
- [待討論] 解鎖下一個目標

## 遊戲內容

- [決定] Daily Adventure
  - 每日可完成的小任務
  - 支援完成報告
- [決定] General Adventure
  - 可以持續多天的任務群組
  - 可以承載章節與劇情
- [決定] 世界
  - 家庭或孩子自己的空間
  - 家具與裝飾
  - 角色與寵物
- [想法] 季節活動
- [想法] 世界區域解鎖
- [想法] 收集圖鑑
