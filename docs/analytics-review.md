# 使用分析覆核

## 統計的意思

- DAU 是台北日曆天內被追蹤到活動的登入帳號數，包含家長與孩子；不是下載人數，也不是家庭數。
- 留存 cohort 從帳號第一次被追蹤到開啟 App 起算，不是安裝日。D7 必須等該 cohort 的第七天完整結束，才適合呈現為確定數值。
- Session 使用時間只計算前景可見期間。定期 checkpoint 降低強制關閉造成的遺漏，但最後一次 checkpoint 之後未送達的時間仍可能遺失，不能宣稱百分之百精確。
- 場景停留應排除背景與遮住世界的功能頁；事件只是已觀測的行為，不能單憑最後畫面斷言使用者不喜歡該畫面。
- 舊版 App 沒有送出的事件不能回補。任務、進度等既有資料與新追蹤事件必須分開解讀。

## 發現的問題

本次覆核在原始實作確認：

1. 分析 migration 撤銷 `authenticated` 對 `private` schema 原有的 USAGE。遠端實際以 authenticated 呼叫既有 helper 時出現 `42501 permission denied for schema private`。
2. 看板使用最後 N 筆資料代替最近 N 個日曆天；缺少今天資料時可能顯示舊日 DAU。
3. 留存包含尚未完整觀測的日期，讓未成熟 D7 看起來像 0%。
4. 登入與重新整理失敗的訊息未完整顯示；非同步請求缺少帳號切換隔離。
5. 時間只靠離開事件、重送缺少去重 ID，可能漏計或重複計算；點擊收集文字也可能帶入使用者內容。
6. 原有小數秒數 SQL 正規表示式錯誤，且教學步驟轉型沒有安全上界。
